# FranchiseOps Database

This folder contains the database schema and datasets used for the FranchiseOps AI project.

## Database Schema

`schema.sql` contains the SQL definitions for the project database tables.

## Dataset

The `data/` folder contains the datasets used by the FranchiseOps system:

- franchises.csv
- outlets.csv
- food_items.csv
- outlet_menu.csv
- sales.csv
- inventory.csv
- stock_movements.csv
- reorders.csv
- staff.csv
- attendance.csv
- marketing_campaigns.csv
- outlet_performance.csv
- validation_report.csv

## Milestone Coverage

The database supports:

- Outlet Performance Intelligence
- Inventory Intelligence and Optimization
- Workforce Intelligence
- Marketing Intelligence

## Database Platform

The database is implemented using PostgreSQL through Supabase.

## Validation

`validation_report.csv` contains the validation results for the generated dataset.
